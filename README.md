# Pagefind

This fork's `low-memory-1.5.2` branch adds consuming Rust-library finalization and
includes the original prebuilt 1.5.2 browser assets. See [LOW-MEMORY.md](LOW-MEMORY.md)
for the patch, provenance and tests.

Pagefind is a fully static search library that aims to perform well on large sites, while using as little of your users’ bandwidth as possible, and without hosting any infrastructure.

The full documentation on using Pagefind can be found at https://pagefind.app/.
